# 阿特師的協調作用島

可部署到 GitHub Pages 的靜態互動課程網站。此版本整合先前的六座協調作用島、搜尋、圖鑑、相簿、水獺拍照、留言、證書、會考十題快答與生物模擬室。

## 本機預覽

請從 `site/` 啟動靜態伺服器，例如：

```powershell
npx serve .
```

不要直接以 `file://` 開啟，因為瀏覽器會阻擋 `content-coordination.json` 的 fetch。

## 教學功能

- 6 座主題不同的生物協調島嶼與 3D 地圖
- 教材、學習單、隨堂測驗與 10 題教師開啟快答
- 神經傳導、血糖負回饋、植物向光性模擬
- localStorage 保存探索、學習單、答題、星星、留言、相簿與主題設定
- 完成所有島嶼與任務後解鎖證書
